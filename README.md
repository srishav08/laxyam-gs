# Laxyam GS Academy

A responsive, buildless informational website. Serve `dist/` with any static web server.

## Change the theme
Edit the `:root` block at the top of `dist/styles.css`. `--primary`, `--primary-dark` and `--primary-soft` control the brand palette throughout the site.

## Contact form
The enquiry form validates the supplied information and opens a pre-filled email to laxyamgsacademy@gmail.com. Visitors must send it using their email app. No enquiries are stored or automatically delivered by this static website. To accept submissions directly, connect a form backend or email service.

Course listings are introductory examples based on the requested SSC, Railway and general exam categories. Confirm exact exams, availability, batch schedules and syllabus before announcing admissions.
